# Student Project (학생 성적 관리 시스템)

Node.js(프론트엔드)와 Spring Boot(백엔드), 그리고 MySQL을 사용하여 구현한 풀스택 성적 관리 시스템입니다. 
Docker Compose를 통해 개발 환경을 완벽하게 자동화하였습니다.

## 🚀 주요 기능
* **학생 정보 관리**: 학생 명단 등록/조회/수정/삭제
* **성적 관리**: 학생별 성적 등록/조회/수정/삭제 및 평균 자동 계산
* **데이터 시각화**: 광고/클릭 데이터 및 회원 정보 관리

## 🛠 Tech Stack
* **Frontend**: Node.js
* **Backend**: Spring Boot
* **Database**: MySQL 8.0
* **Infrastructure**: Docker Compose

## 🚀 시작하기 (Quick Start)

별도의 복잡한 설치 과정 없이, 아래 명령어로 모든 환경을 실행할 수 있습니다.

### 1. 사전 준비
* [Docker Desktop](https://www.docker.com/products/docker-desktop/)이 설치되어 있어야 합니다.

### 2. 프로젝트 실행
터미널에서 프로젝트 루트 경로로 이동한 뒤, 아래 명령어를 입력하세요.

```bash
docker compose up -d
